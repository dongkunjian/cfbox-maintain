GitHub 订阅设置

用于「一键上传 GitHub」
获取 Token：GitHub → 头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，勾选 repo，生成后粘贴到这里保存（仅存本机 gh_settings.json）。
上传后订阅地址为 https://raw.githubusercontent.com/仓库/分支/文件， cfbb 管理页「自定义优选」填这个地址（汇聚订阅），以后每次优选后点「一键上传 GitHub」即可，Karing 更新订阅自动生效。
