  Karing / CFBox 一键维护工具  使用说明
═══════════════════════════════════════════════════════

【目录结构】
E:\karing一键维护\
├─ 网页版启动.bat            ← 推荐！双击这个打开可视化面板
├─ index.html                ← 网页界面
├─ webui.py                  ← 网页服务（python，无需安装依赖）
├─ CFBox一键维护.bat         ← 命令行版（备选）
├─ cfbox_maintain.py         ← 核心脚本（两种模式共用）
├─ cfbb_nodes_to_paste.txt   ← 要上传到 cfbb 的节点内容
├─ cfbb_login.txt            ← cfbb 管理页登录密码（自动登录用）
├─ xray_test.json            ← 测速模板（勿删）
├─ xray\                     ← 测速核心工具（勿删）
└─ 使用说明.txt              ← 本文件


【网页版用法（推荐）】
 1. 双击「网页版启动.bat」→ 自动打开浏览器进入面板
 2. 点「▶ 开始优选」→ 等 2~4 分钟，实时看进度
 3. 结果表格出来后点「✓ 更新部署」→ 自动写入 qinyu（CFBox订阅）
 4. 点「⚡ 自动上传到 cfbb」→ 在对话里发送“上传cfbb”
    → 我会自动在 cfbb 管理页填表保存（无需复制粘贴）
 5. Karing 里更新「自己用」「CFBox订阅」即可

 网页面板保持打开（黑窗口别关），随时可以再来一次。

【命令行版（备选）】
 双击 CFBox一键维护.bat（正式）或：
   python E:\karing一键维护\cfbox_maintain.py --dry-run（预演）


【什么时候用】
感觉 Karing 速度明显变慢（节点挂了/被限速）时跑一次即可。
脚本会自动：挑一批新节点 → 实测速度 → 更新 qinyu（CFBox订阅）→
生成 cfbb（自己用）要粘贴的节点 → 打开管理页。


【使用方法】

 方式1：正式运行（会更新线上配置）
   双击 CFBox一键维护.bat，等待约 2~4 分钟。
   完成后按屏幕提示：
     1) qinyu（CFBox订阅）已自动更新，无需操作
     2) cfbb（自己用）需手动：自动打开的管理页里
        「⚡️优选订阅生成 → 自定义优选」输入框，清空后
        粘贴 E:\karing一键维护\cfbb_nodes_to_paste.txt 的内容，点「保存」
     3) 打开 Karing → 更新「自己用」和「CFBox订阅」，即可生效

 方式2：预演（只看结果，不改配置）
   打开命令行（Win+R → cmd），输入：
     python E:\karing一键维护\cfbox_maintain.py --dry-run
   会完成全部分析并打印 TOP 节点，但不写入任何线上配置。

 方式3：调整速度门槛
     python E:\karing一键维护\cfbox_maintain.py --min-kbps 15000
   （默认 10000，即单连接 10 Mbps 以上才入选）


【脚本自动做的事】
  1. 从 4 个优选源拉取候选 IP（混合池 500+ / 日本随机 / JP 专项）
  2. 并发 TCP 连通性 + 延迟筛选（160ms 内）
  3. xray 真实 VLESS+WS 隧道测速（并发 4 路）
  4. 保底保护：当前在用的好节点只要还活着就保留，
     即使这次优选全军覆没，配置也不会变差
  5. 选出 TOP 8 节点 → 自动写入 qinyu 的 KV 配置
  6. 生成 cfbb 粘贴文件并打开管理页


【想长期维护的要点】
  1. 每次跑完，把新选出的最快节点更新到脚本顶部
     BASELINE_NODES 列表里（保持保底池新鲜）
  2. 保底节点建议保持 4~8 个，防止优选源抽风
  3. 如果你换了部署域名/UUID，改脚本顶部 QINYU / CFBB 配置


【依赖】
  - Python 3（本机已装）
  - Windows 自带 curl.exe
  - xray.exe（已包含在 xray\ 目录）


【常见问题】
  Q: 提示"没有拉到任何候选 IP"？
     A: 网络不通或优选源挂了，稍后重试；保底节点仍会保留。
  Q: 提示"没有节点达到速度门槛"？
     A: 当前优选源整体质量差，可降低门槛重试：
        --min-kbps 5000
  Q: cfbb 管理页没自动打开？
     A: 手动打开 https://cfbb.dongkunjian.ccwu.cc/admin 操作。
  Q: 想知道现在用哪个节点？
     A: Karing 界面查看当前连接即可；本脚本不碰 Karing 配置。
